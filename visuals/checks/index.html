    What the checks caught

    Building this surfaced 11 real defects. The interesting part is which check found each one.

    Dots show the check that caught each defect. No single check caught them all.

    What it shows

    • The structural checks (schema validation and the strict build) caught none of these, because they test form, not fidelity. A clean build does not mean correct content.
    • The most valuable check was measuring completeness against the source (the coverage check), which exposed a factory-reset procedure that a well-meant cleanup step had silently deleted.
    • Several defects were found only by reading the output against the source. Automated checks narrow the search; they do not replace looking.

    The defects
